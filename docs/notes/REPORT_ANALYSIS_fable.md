## P1 摘要结论句
本工作在 Tanks&Temples Truck 场景上完整复现了 3DGS(7k) → coarse SuGaR(15k, density 正则) → Poisson 网格提取的短流程，并在 coarse 训练主循环中加入像素级的深度-法向一致性正则（DNC）。对照实验（λ=0 / 0.05 / 0.2，各一次完整重跑）表明：在 7k→15k 的短预算下，DNC **没有**带来几何改善，反而随 λ 增大单调损害渲染与几何；λ=0.2 时场景坍缩为大尺度半透明薄片。进一步的诊断实验（切断损失对深度的梯度）把 PSNR 从 13.24 dB 恢复到 24.40 dB（λ=0 为 24.62 dB），证实退化源于"抹平渲染深度"这一平凡解，但几何指标仍未优于基线。本报告如实报告这一负结果与其机理，并在写作后期核实到官方仓库已内置同类正则（dn_consistency），已将其作为额外对照组。

## P2 H1/H2/H3 判定
- H1（几何改善）：**不支持**。λ=0.05 时碎片分量 2137→2324、稀疏点到网格距离中位数 0.0687%→0.1421%（相对相机尺度）、二面角均值上升；λ=0.2 的碎片数下降到 1177 是网格整体坍缩（面数 370k→223k，包围盒从 ±23 缩到 ±9.7）的副产物，不构成证据；detach 组碎片 2142、距离中位数 0.0839%，仍不优于 λ=0。
- H2（渲染代价 ±0.5 dB 内）：**不支持**。λ=0.05 为 −2.17 dB，λ=0.2 为 −11.38 dB。仅 detach 变体满足（−0.22 dB）。
- H3（与原有 SDF 法向损失不冲突）：**仅在"两者同时下降"的操作性定义下成立**；两组 λ 的 L_dnc 与 sdf_better_normal_loss 均单调下降，但几何并未变好，说明"损失下降"与"表面质量"在此脱钩，H3 的定义本身不足以作为质量判据。

## P3 未打补丁 baseline 与 λ=0 的差异
阶段 2 用官方原版代码跑的 coarse_baseline（无 seed、无插桩）与打补丁后 λ=0 的 coarse_base_seed0 相比：PSNR 24.653 vs 24.620，SSIM 0.8564 vs 0.8555，距离中位数 0.0684% vs 0.0687%，连通分量 2237 vs 2233，碎片 2147 vs 2137，高斯数 429,075 vs 429,423。差异均在 CUDA 光栅化非确定性与随机采样带来的抖动量级内，据此判断 λ=0 时补丁没有改变原有代码路径（日志中也无任何 DNC 分支输出）。

## P5 定量解读
渲染指标随 λ 单调恶化：PSNR 24.62 → 22.45 → 13.24 dB，LPIPS 0.203 → 0.346 → 0.646。几何指标同向：稀疏点到网格距离中位数 0.0687% → 0.1421% → 0.8392%，距离 <1% 相机尺度的稀疏点比例 97.7% → 87.3% → 55.5%。训练日志显示 λ=0.2 组高斯最大尺度从 8.35 增至 83.68、不透明度均值从 0.65 降至 0.45，即高斯被拉大且变透明。L_dnc 末值 λ=0.2 组最低（0.046），λ=0.05 组 0.240，detach 组 0.292：**L_dnc 越低，结果越差**，说明该损失在本设置下主要被"抹平深度"这条捷径最小化，而非被"法向对齐"最小化。detach 组切断深度梯度后，PSNR 回升 11.16 dB、每迭代耗时降低 10%、显存少 811 MiB，但几何指标与 λ=0 持平或略差。

## P6 定性解读
λ=0.05 的测试视角渲染中卡车本体基本正常，但地面被抹成一块均匀灰板，是退化的早期形态；λ=0.2 整幅画面糊成色块。DNC 中间量可视化显示：SuGaR 的深度图由每个高斯中心的视空间 z 经 alpha 合成得到，是分片常数的阶梯面，对其做有限差分得到的几何法向 N_d 在平坦地面上呈密集条纹噪声。要降低 1−|cos(N, N_d)|，把法向对准这种噪声代价很高，而让若干大尺度高斯把深度真正抹平则代价很低，优化因此走向后者。detach 组的深度图在 15000 迭代仍保留车头格栅、车轮、栏板、树干等结构（深度梯度 >0.02 的像素占 12.8%，λ=0.2 非 detach 组仅 1.5%），证实平凡解只在梯度流经深度时出现。

## P7 失败案例
1. 大面积弱纹理区域（地面）最先被抹平：λ=0.05 即出现，是"深度局部平面化"零损失捷径的直接体现。
2. λ=0.2 全场景坍缩：高斯尺度增大 10 倍、不透明度双峰化，网格面数减少 40%、包围盒收缩到原来的 40%，碎片数"下降"实为塌缩假象，提醒单一拓扑指标不能脱离几何精度解读。
3. 阶梯状深度带来的法向噪声：有限差分法向在物体边缘与纹理丰富处噪声更大，掩码只能剔除深度断崖，无法剔除阶梯噪声。
4. 工程失败：作业超时导致 14900/15000 的两组全部重跑；并发编辑运行中的脚本导致一次网格提取中断。均已记录并补跑。

## P8 代价
每迭代耗时：λ=0 组 91.1 ms，λ=0.05 组 104.5 ms，λ=0.2 组 107.9 ms，detach 组 96.7 ms（额外两次光栅化；detach 省去深度反向）。峰值显存 7.4 → 7.6 / 8.4 / 7.8 GB。总墙钟 12.1 → 13.9 / 14.4 / 12.9 分钟。高斯数量无显著差异（约 42.9 万）。代价可接受，但在本设置下没有换来收益。

## P9 λ 敏感性
λ 从 0.05 到 0.2 的四倍变化使 PSNR 差 9.2 dB、几何距离中位数差 5.9 倍，敏感性极高，说明该正则没有一个"安全的"权重区间可以既起作用又不伤害渲染；官方仓库选择 0.05 并从 9000 迭代开启（与本工作起点相同），本工作 λ=0.05 组仍显著退化，差异来源待官方对照组（§12）确认。

## P10 结论
在 SuGaR coarse 阶段直接加入 2DGS 式的深度-法向一致性正则，在短预算下不能改善网格几何，且存在随权重增大而单调恶化的"抹平深度"平凡解；切断深度梯度可消除平凡解并保住渲染质量，但也失去了该正则对几何的作用。负结果的根因在于 SuGaR 以高斯中心深度做合成，得到的深度图不具备计算可靠几何法向所需的平滑性，这与 2DGS 用射线与面片交点得到连续深度的前提不同。本工作的贡献是：完整可复现的短流程、可控的对照与消融、对该正则失效机理的可视化诊断，以及一个可复用的实现与评测框架。

## P11 下一步
1. 用射线-高斯交点深度（RaDe-GS 思路）或中值深度替代中心深度合成，再评估 DNC。
2. 引入 alpha 门控与线性 warm-up（Gaussian Surfels 思路），并与官方 dn_consistency 做受控消融。
3. 转向 Poisson 前的表面点/高斯可靠性过滤（TrimGS、Gaussian Surfels 的体素裁剪思路），直接针对碎片问题，不需重训。
4. 补 checkpoint 保存与断点续训，避免作业超时导致的重跑。
